# 基于DPU卸载的图基索引搜索系统


本项目是基于 Nvidia bluefield-3 DPU 实现的向量图基索引近似最近邻检索系统。系统将图基向量的检索状态划分为逼近与收敛阶段，我们的洞察发现，在收敛阶段中，向量搜索区域趋于稳定，候选集变动较小。因此系统将收敛阶段的工作卸载到DPU自带的Arm soc执行，同时将其内存作为动态的工作集维护，从主机内存中读取所需的检索数据。

本系统主要贡献点为：

+ 基于离线预训练与在线收敛候选集状态的收敛状态预测
+ 高效的DPU内存工作集维护，最大程度实现数据复用
+ RDMA 与 DMA 同步数据搬运，利用 DMA 承担前期的图预测拓扑结构，通过 RDMA 对缺少数据进行及时取用
+ 网络流的 I/O 优化，通过深入挖掘 Soc 在 RDMA 上的特性，将发送数据流进一步优化



## BlueField-2 v1 实施计划

当前 v1 目标设备为 BlueField-2。完整实施顺序、模块边界、最小协议及验收标准见 [v1 实施计划](implementation_plan_v1.md)；已确认决策汇总见 [规划记录](planning/v1_decisions.md)。无设备阶段 P0–P5 已实现并验收：共享搜索、软件交接闭环与真实 Comch/DMA 后端，Host x86_64 和 SoC AArch64 均已编译链接。SIFT 全部 10,000 条查询在 ef32/64/128 下共 30,000 条基线对照通过。

交付细节见 [实施报告](docs/implementation_report_v1.md)，复现与未来真机入口见 [构建运行说明](docs/build_and_run.md)。当前尚无 DPU，真机 DMA 与性能未验证；上文 BF3、RDMA 和动态复用是项目研究背景，当前 BF2 v1 范围以正式计划为准。
